# Тренажёр китайского языка (HSK1)

Интерактивный консольный тренажёр для изучения китайских слов уровня HSK1.

## 📋 Описание

Программа представляет собой полноценный тренажёр для изучения и закрепления китайской лексики уровня HSK1. Слова разбиты по тематическим категориям, что позволяет эффективно изучать язык по темам.

## ✨ Возможности

- **127 слов уровня HSK1** в базе данных
- **8 тематических категорий**:
  - Приветствие (问候)
  - Общение (交流)
  - Семья (家庭)
  - Числа и время (数字和时间)
  - Путешествие (旅行)
  - Еда и напитки (饮食)
  - Места и направления (地点和方向)
  - Описание предметов (描述)

- **4 типа вопросов**:
  - Китайский → Перевод
  - Перевод → Китайский
  - Пиньинь → Китайский
  - Китайский → Пиньинь

- **Гибкие настройки**:
  - Выбор конкретной темы или всех тем сразу
  - Настройка количества вопросов (5-20)
  - Случайная генерация вопросов

- **Подробная статистика**:
  - Подсчёт правильных ответов
  - Процент успешности
  - Работа над ошибками с показом правильных ответов

## 📖 Использование

### Главное меню

При запуске программы вы увидите главное меню с опциями:

1. **Начать тестирование** - запуск викторины
2. **Просмотреть все темы** - показать список доступных тем
3. **Просмотреть слова темы** - просмотреть все слова выбранной темы
4. **Выход** - завершение работы программы

### Тестирование

1. Выберите тему (номером или названием ключа)
2. Укажите количество вопросов (5-20, по умолчанию 10)
3. Отвечайте на вопросы, выбирая номер правильного варианта
4. После завершения получите статистику и разбор ошибок

## 🔧 Технические детали

### Модуль vocabulary.py

Содержит базу слов и функции для работы с ней:
- `VOCABULARY` - словарь со словами по темам
- `get_all_words()` - получить все слова
- `get_topic_keys()` - получить список ключей тем
- `get_topic_name(key)` - получить название темы
- `get_words_by_topic(key)` - получить слова темы
- `get_total_words_count()` - общее количество слов

### Модуль quiz.py

Содержит логику викторины:
- `QuizQuestion` - класс вопроса
- `QuizSession` - класс сессии тестирования
- `create_quiz_session()` - фабрика для создания сессий

### Типы вопросов

1. **chinese_to_translation** - показывается иероглиф, нужно выбрать перевод
2. **translation_to_chinese** - показывается перевод, нужно выбрать иероглиф
3. **pinyin_to_chinese** - показывается пиньинь, нужно выбрать иероглиф
4. **chinese_to_pinyin** - показывается иероглиф, нужно выбрать пиньинь
